# Лабораторная работа №5 — Функции высшего порядка и паттерн «Стратегия»

## Цель работы

- Освоить передачу функций как аргументов в другие функции и методы.
- Научиться применять встроенные функции высшего порядка: `map`, `filter`, `sorted`.
- Понять концепцию паттерна «Стратегия» и реализовать его на Python.
- Освоить `lambda`-выражения и их практическое применение.
- Интегрировать функциональный стиль с объектно-ориентированным кодом из предыдущих ЛР.

## Реализованные функции и стратегии

Все стратегии и вспомогательные функции вынесены в отдельный модуль `strategies.py`.

### Стратегии сортировки (key-функции)
- `by_name` – сортировка по имени
- `by_damage` – по базовому урону
- `by_level` – по уровню
- `by_rarity_weight` – по числовому весу редкости
- `by_total_attack_power` – по реальному урону (вызовом `attack()`)

### Функции-фильтры (предикаты)
- `is_melee` / `is_ranged` – фильтр по типу оружия (через `isinstance`)
- `is_not_broken` – только исправное оружие
- `make_damage_filter(min, max)` – **фабрика функций**, возвращающая фильтр по диапазону урона (замыкание)

### Функции для `map`
- `to_display_string` – преобразование в строку через `display_info()`
- `apply_discount(percent)` – фабрика, создаёт функцию для снижения урона (используется в `apply`)

### Паттерн «Стратегия» через callable-объекты
- `UpgradeStrategy` – повышение уровня оружия (вызов `upgrade()`)
- `BreakAllStrategy` – поломка оружия

Эти классы реализуют метод `__call__`, поэтому их экземпляры можно вызывать как функции и передавать в `apply()`.

### Расширенная коллекция `WeaponInventory`
Добавлены методы:
- `sort_by(key_func, reverse)` – возвращает новую отсортированную коллекцию
- `filter_by(predicate)` – возвращает новую отфильтрованную коллекцию
- `apply(func)` – применяет функцию к каждому элементу (модифицирует объекты), возвращает `self` для цепочек
- `map_to(transform_func)` – возвращает список результатов преобразования
- `get_names()` – пример использования `lambda`
